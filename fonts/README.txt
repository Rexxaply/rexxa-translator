Font bawaan aplikasi (Comic Neue, lisensi SIL OFL — lihat ComicNeue-OFL.txt), diunduh otomatis saat build.

Font milikmu sendiri JANGAN ditaruh di sini (folder ini diganti setiap update). Pilih salah satu:
- Pasang font di Windows (klik kanan file .ttf > Install). Wild Words / Anime Ace yang terpasang otomatis dipakai.
- Atau taruh .ttf/.otf di %APPDATA%\RexxaTranslator\fonts
